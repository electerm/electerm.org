# electerm 窗口不透明度：让终端直接透过去

你正在敲一行很长的命令，参数写在终端后面的浏览器标签页里。或者一边照着 PDF 里的操作手册，一边在 SSH 里干活。于是开始反复横跳：终端、浏览器、终端、浏览器——为了一行命令切四次窗口。

electerm 给这件事准备了一个"一个数字"的答案：**窗口不透明度（opacity）**。调低它，整个 electerm 窗口变半透明，后面的应用直接透出来。看一眼上面的横幅动画——这就是这个功能的全部。

这是 electerm 有意做小的一个功能。只做一件事，只有一个设置，但在你需要它的那些日子里，你会纳闷为什么每个终端都没有它。

## 滑杆在哪

设置 → **设置** → `opacity`。

- **范围：** `0` 到 `1`，步进 `0.05`。
- **默认：** `1`——完全不透明，也就是你现在看到的样子。
- **即时生效。** 往下拖窗口就地变透，拖回 `1` 就实回去。不用重启，不断连，会话完全无感。
- **只有 macOS 和 Windows 桌面端有。** 网页版（`electerm-web` / `demo.electerm.org`）里这个选项是藏起来的——浏览器标签页没法让自己所在的窗口变透明，没什么可设的。Linux 上也不能用。

几个顺手的起点：`0.85` 是"微微透、还能舒服看几小时"；`0.7` 是照着后面抄东西的甜点；`0.5` 以下终端自己就难读了——适合盯一分钟，不适合干一天活。

## 它到底改了什么

它变淡的是**所有东西**，不只是背景：

- 这个值存为 `config.opacity`（默认 `1`，见 `src/client/common/default-setting.js` 和 `src/app/common/default-setting.js`）。
- 渲染层把它变成一条作用在整个应用根节点上的 CSS（`src/client/components/common/opacity.jsx`）：

```css
#outside-context {
  opacity: 0.7 !important;
}
```

- 同时把页面和 Electron 窗口背景一起切成透明（`html`/`body` → `transparent`，经 IPC 调用 `src/app/lib/ipc.js` 里的 `setBackgroundColor('#33333300')`），你看到的透过来的东西，就是窗口后面真实的应用。调回 `1` 时实色 `#333333` 背景恢复，这条规则整个删掉。
- 窗口创建时就是按可透明建的（`src/app/lib/create-window.js` 里 `transparent: true`）。透明窗口合成只在 macOS 和 Windows 上支持——所以这个功能也只在这两个平台上能用。

实话实说：**字也会变淡**。这是整窗不透明度，不是只透背景。终端背景图能做到"背景淡、字还亮"；opacity 做不到——`0.6` 时你的 shell 输出也只有 60%。这就是代价，所以推荐值才一直偏高。

## 什么时候好用

**照着后面的文档抄参数。** 降到 `0.7` 左右，隔着终端读浏览器，把命令一次敲对。抄完调回去。

**跟着操作手册做。** 步骤在 wiki 里，命令在 SSH 里。不用来回背第 4 步。

**干活时顺便盯着点东西。** 仪表盘、构建进度、视频会议的共享屏幕——把它留在 electerm 后面，`0.75` 左右，两边都看得见。

**小屏幕。** 13 寸本上根本摆不下并排窗口。半透明就是不用管理窗口的"并排"。

## 局限和实话

- **要么全透，要么不透。** 标题栏、标签栏、对话框、菜单——一起淡。没有"只透终端"模式。如果你想要"背景淡、字还亮"，请用**终端背景图**，那是按终端算的，不动文字。
- **太低了伤眼。** `0.5` 以下语法高亮先糊，细字体先没。直播或截图时，观众会比你先受不了。
- **不附带点击穿透。** 看得见不等于点得着——鼠标事件还是落在 electerm 上。真要操作后面的应用，还是得切过去。
- **只有 macOS 和 Windows，没有 Linux。** 合成透明窗口还比实色窗口更吃 GPU。如果闪烁或透得奇怪，调回 `1` 永远是对的。
- **别长期停在低值。** 不透明度是为某个任务开的模式，不是主题。抄完就调回去。半夜读日志的你，会感谢现在调回去的你。

## 一句话总结

- **位置：** 设置 → 设置 → `opacity`，`0`–`1`，步进 `0.05`，默认 `1`。
- **`1`** = 实色，**`0.85`** = 微微透，**`0.7`** = 隔着读后面，**`0.5` 以下** = 只适合盯一会儿。
- **淡的是整个窗口**，字也包括——这正是它和终端背景图的区别。
- **只有 macOS 和 Windows 桌面端有**——Linux 上不能用，网页版里没有。
- **习惯：** 为一件事调低，做完调回 `1`。
