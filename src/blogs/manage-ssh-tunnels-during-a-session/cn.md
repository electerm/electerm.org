假设你正通过 SSH 查看 Web 应用的日志，想用浏览器打开页面，对照着看一次请求。应用只监听服务器的回环地址，端口是 `3000`。从 electerm 5.20.0 开始，你可以直接在当前 SSH 标签页里把这个端口转发到自己的电脑，一边浏览页面，一边看日志。[v5.20.0 发布说明](https://github.com/electerm/electerm/releases/tag/v5.20.0)

## 在本地浏览器打开远程应用

1. 在已连接的 SSH 标签页里，点击会话工具栏上的插头图标，打开 **SSH隧道** 面板。在手机上，先展开 **⋯** 菜单。
2. 点击 **新建 SSH隧道**，选择 **L→R**（本地到远程）。在 **本地** 一栏填入主机 `127.0.0.1` 和本机空闲端口，例如 `8080`。在 **远程** 一栏填入主机 `127.0.0.1` 和端口 `3000`。这里的远程地址是 SSH 服务器访问应用时使用的地址。
3. 给隧道起个名字，例如 `web-preview`，然后点击 **启动**。等这一行显示 **运行中**，在本机浏览器打开 `http://127.0.0.1:8080`，就能通过当前 SSH 连接访问服务器上的应用。

## 停止、重新启动或移除隧道

预览结束后，点击 `web-preview` 旁的 **停止** 即可释放本地端口。面板会保留这条隧道的地址，下次要看页面时，再点 **启动** 即可。终端和当前标签页中的其他隧道可以继续使用。点击该行的 **−** 图标可以移除这条记录。如果隧道还在运行，也可以直接点 **−** 将它停止并移除。

如果启动失败，面板会在对应的隧道下显示错误信息。例如，遇到本地端口 `8080` 已被占用时，可以移除这一行，换个空闲的本地端口重新添加。

## 重新连接后，哪些隧道会启动？

从工具栏添加的隧道仅在本次 SSH 连接期间有效。重新连接时，electerm 会再次启动书签里保存的隧道，包括你在上次会话中手动停止或移除的那些。如果每次连接都要使用 `web-preview`，可以在书签的 SSH 隧道设置中添加它，然后保存书签。

工具栏也支持 **R→L**、**-D socks** 和 **-R socks**。每种模式的转发方向和配置示例可参阅 [SSH 隧道指南](/blogs/ssh-tunnels/cn/)。
