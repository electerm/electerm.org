# Electerm 终端 + SFTP 分屏：点一下，两边一起看

你在服务器上 `ls` 看看有什么，切到文件标签页把包拖上去，再切回来解压，再切过去确认解出来没有。每次切换都是一秒钟加一次注意力切换——等文件面板出来，刚才记住的文件名已经忘了一半。

Electerm 的解法就是会话工具栏上的一个图标：**分屏开关**。点一下，经典的终端/SFTP 标签页切换就变成**分屏**——终端在一边，SFTP 文件管理器在另一边，连的是同一台主机，两边一起看。看一眼页眉上的动画——标签页，点一下，分屏。这就是该功能的全部样子。如果希望一开就是这样，**设置 → 终端**里还有一个对应开关，让每个新会话默认分屏打开。下面两种方式都会讲。

功能视频：[Electerm Terminal and SFTP Split View](/videos/electerm-terminal-and-sftp-split-view/)。

## 经典标签页 vs 分屏

开了 SFTP 的 SSH 会话，默认长得像经典标签页。终端窗格上方有两个类型标签——**SSH** 和 **SFTP**——一次只能看一边：

```
[ SSH | SFTP ]   <- 类型标签，一次显示一格
+----------------+
|  终端          |
|  $ ls -la      |
+----------------+
```

点 **SFTP**，终端滑走，文件列表占满整个窗格；点 **SSH**，再回来。这和"PuTTY + WinSCP 塞进一个窗口"或两个浏览器标签页是一个思路：干净，每一边都独占最大空间，但永远**不能同时看见两边**。

分屏则是把两个窗格同时挂出来：

```
[⧉ 分屏已开]
+--------------+--------------+
|  终端        |  SFTP        |
|  $ tar xzf  |  app/ logs/  |
|  app.tar.gz  |  app.tar.gz  |
+--------------+--------------+
```

注意哪一样东西消失了：`SSH | SFTP` 类型标签。分屏下没有东西需要切换，控制条上只剩那一排图标。命令和它要动的文件同时在屏幕上。这正是 MobaXterm、Xshell、WindTerm、Tabby 带火的那种布局——用过分屏的人，很少再愿意回去翻标签页。

本地终端一样能分屏。本地会话的两个标签是**终端 | 文件管理器**，分屏后就是本地 shell 配本地文件管理器。真正没有第二格的是 RDP、VNC、网页、telnet、串口和纯 FTP 会话——这些会话不显示分屏图标。

## 两种打开方式

**设置项——默认就分屏。** 设置 → 终端 → **在分屏视图中显示终端和SFTP**。默认关闭。打开之后，新建的 SSH 或本地会话都以分屏启动；关掉则以标签页启动。这个选择重启后依然有效，属于设一次就忘的那种。

**工具栏图标——只分这一格。** 会话控制条里的分屏图标，把当前标签页在两种模式之间切换，不重连。它对所在标签页永远优先：`web-01` 可以一直分屏，旁边的串口控制台照样全宽；把图标点回标签模式，也不会改动你的全局设置。

两者是叠加关系：设置决定会话**怎么打开**，图标决定它**现在是什么**。

## 开关在哪里

看**会话控制条**——终端窗格正上方那条细条，开头是 `SSH | SFTP` 类型标签的那条。类型标签（显示时）后面就是那一排图标：

1. 回形针——SFTP 路径跟随终端
2. **分屏——就是这篇的主角**（两个并排的小矩形）
3. 心跳——keepalive 空闲保活，连接不会因为不说话掉线（[会话保活](/blogs/session-keepalive/cn/)）
4. 广播——将输入镜像到所有终端
5. ……右侧还有换行、全屏、搜索

点一下分屏图标，当前会话立刻在标签模式和分屏模式之间切换，**不用重连**。再点一下就回去。这个状态按会话标签页保存，所以 `web-01` 可以一直分屏，旁边的串口控制台照样全宽。

> 图标的出现是有条件的：会话得在书签里同时启用 SSH 和 SFTP，会话窗格还得够大（见下文）。手机上不显示这个图标——靠 `SSH | SFTP` 标签切换。

## 30 秒第一次分屏

1. 打开任意开了 SFTP 的 SSH 书签（或一个本地终端）。
2. 在会话控制条里找到分屏图标（回形针后面第二个）。
3. 点它。终端让出一半窗格，SFTP 文件管理器占另一半——宽窗口在右边，高窗口在下面。
4. 中间的缝可以拖，想让终端宽一点就往左/上拖。默认两边各一半，每边可以从 20% 拖到 80%。
5. 再点一次图标。回到全宽标签页。

不用存设置，不用重连，不用开布局对话框。如果每个会话都想这么干，就把**设置 → 终端 → 在分屏视图中显示终端和SFTP**打开，省掉第 3 步。已经开着的会话保持当前模式不变——设置只影响新建的会话。

## 分屏方向跟着窗口形状走

分屏不是固定的左右。它看会话窗格的形状：宽窗格就左右分，高窗格就上下分。所以同一个会话，在宽显示器上是左右分屏，窗口拉窄或给它排进一列后就变成上下分屏。

它也确实需要地方。会话窗格宽度不到 640px、高度又不到 400px 的时候，对半分没有意义，分屏保持关闭：图标不显示，`SSH | SFTP` 标签照常工作。把窗口拉宽或让窗格长高一点，图标就回来了。

## 什么时候分屏最爽

**解压即确认。** 左边 `tar xzf release.tar.gz`，右边立刻看到 `release/` 冒出来。不用翻标签页确认解压成功没有。

**改完即跑。** 在 SFTP 格里双击 `app.js` 本地编辑，保存即上传，`node app.js` 或 `systemctl restart app` 就在左边一眼的地方。

**追磁盘占用。** `du -sh *` 说 `logs/` 有 4 GB，文件夹本来就在右边摆着——右键下载或删除，收工。

**逛一台不熟的机器。** 左边 `cat docker-compose.yml`，右边项目树一直可见。不用再靠 `ls` 回忆结构，因为文件面板本身就是一个排好序、带大小、可点击的 `ls`。

**拖文件不用找地方。** 本地文件拖进 SFTP 格时终端一直可见，进度条一走完，安装命令立刻就能敲。（拖到终端上则是走 trzsz / zmodem 上传，**设置 → 终端 → 拖放文件到终端的行为**决定要不要先问一声。）

还有一个附带的好处：分屏开着的时候，底部工具栏一直陪着你——即时命令、命令历史、批量输入在文件格里也照样能用，因为会话仍算作"在终端里"。标签模式下切到 SFTP 标签页，它们就收了回去。

标签模式也有赢的时候：窄笔记本屏、想独占每一列的 `vim`、铺满屏的 `htop`。所以它是个开关而不是设置项——按任务翻，而不是按安装翻。（反过来那种"我就是要默认分屏"的人，就是上面那个设置项存在的理由。）

## 和路径跟随是绝配

分屏解决"两边一起看"，**SFTP 路径跟随终端**解决"两边看同一个目录"：shell 里 `cd`，文件面板跟过去；文件面板里点开文件夹，shell 跟过去。回形针图标就挨着分屏图标不是偶然——两个都打开，就是一个位置、两个视图。

完整故事：[SFTP 路径跟随终端](/blogs/sftp-path-follow-terminal/cn/)。如果 `cd` 了面板不动，去那篇的排查清单里看（shell 得是 bash/zsh/sh/ash、得是同主机的窗格、跟随得真的开着）。

## 分屏 vs 会话布局 vs 工作区

三个名字像、活儿不一样：

|  | 分屏（这篇） | 会话布局 | 工作区 |
|---|---|---|---|
| **拆的是什么** | 一个会话标签页里的终端 + SFTP | 窗口里的多个会话标签页（2x2 网格、多列、多行） | 一切——标签页 + 布局，按名字存下来 |
| **入口** | 会话控制条里的分屏图标，或设置 → 终端 | 布局控件 / 状态栏 | 工作区面板 |
| **保存吗** | 设置项决定默认；标签页开着就保持自己的模式 | 窗口开着就在 | 保存，一键恢复标签页 + 布局，含哪些书签标签页是分屏的 |
| **配合** | 永远是起点 | 两台主机左右摆，每台再各自文件分屏 | "前端 + 后端 + 数据库，全部分屏"存成一个动作 |

典型终态：一个叫 `prod` 的工作区，一键打开 `web-01` 和 `db-01` 摆成两列，每个标签页都已经是终端 + SFTP 分屏且跟随打开。每天早上的 routine 变成一次点击。视频：[Electerm Session Layout](/videos/electerm-session-layout/)、[Electerm Workspace](/videos/electerm-workspace/)。

## 排查清单

1. **没有分屏图标？** 要么这个会话没有第二格（本地终端有——网页、RDP/VNC、telnet、串口、纯 FTP 没有），要么书签里 SSH/SFTP 被关了，要么窗格太小分不动（见上）。
2. **有图标但点了没反应？** 会话窗格宽度不到 640px 且高度不到 400px，分屏回退成标签页。把窗口或窗格放大。
3. **分屏方向和想的不一样？** 方向跟着窗格形状走：宽则左右，高则上下。改窗口形状即可切换，中间的缝也能拖。
4. **SFTP 格空白或报错？** SFTP 子系统没起来——权限、`Subsystem sftp` 服务端没开、连接断了。标签模式一样会失败，分屏只是让它看得见。
5. **想默认分屏？** **设置 → 终端 → 在分屏视图中显示终端和SFTP**，默认关闭。新建会话按它来，工具栏图标仍可按会话覆盖。

## 一句话备忘

- **开关** = 会话控制条里的分屏图标（两个小矩形），回形针后面那个。点一下 = 标签页 ↔ 分屏，不用重连。
- **默认** = **设置 → 终端 → 在分屏视图中显示终端和SFTP**（默认关）。新会话按它打开；图标仍可按会话覆盖。
- **方向** = 宽窗格左右分，高窗格上下分。中间可拖，每边 20%–80%，初始各一半。
- **要地方** = 窗格宽于 640px 或高于 400px；否则保持标签页，图标隐藏。
- **支持** = SSH 会话（终端 + SFTP）和本地终端（终端 + 本地文件管理器）。网页、RDP/VNC、telnet、串口、纯 FTP 不支持；手机上不支持，用标签切换。
- **好搭档** = 旁边的路径跟随开关。分屏管一起看，跟随管看同一个目录。
- **放大招** = 会话布局（多标签页同屏）+ 工作区（整套存下来）。
