# Electerm 终端 + SFTP 分屏：点一下，两边一起看

你在服务器上 `ls` 看看有什么，切到文件标签页把包拖上去，再切回来解压，再切过去确认解出来没有。每次切换都是一秒钟加一次注意力切换——等文件面板出来，刚才记住的文件名已经忘了一半。

Electerm 的解法就是会话工具栏上的一个图标：**分屏开关**。点一下，经典的终端/SFTP 标签页切换就变成**左右分屏**——终端在一边，SFTP 文件管理器在另一边，连的是同一台主机，两边一起看。看一眼页眉上的动画——标签页，点一下，分屏。这就是该功能的全部样子。

功能视频：[Electerm Terminal and SFTP Split View](/videos/electerm-terminal-and-sftp-split-view/)。

## 经典标签页 vs 分屏

开了 SFTP 的 SSH 会话，默认长得像经典标签页。终端窗格上方有两个类型标签——**SSH** 和 **SFTP**——一次只能看一边：

```
[ SSH | SFTP ]   <- 类型标签，一次显示一格
+----------------+
|  终端          |
|  $ ls -la      |
+----------------+
```

点 **SFTP**，终端滑走，文件列表占满整个窗格；点 **SSH**，再回来。这和"PuTTY + WinSCP 塞进一个窗口"或两个浏览器标签页是一个思路：干净，每一边都独占最大空间，但永远**不能同时看见两边**。

分屏则是把两个窗格同时挂出来：

```
[ SSH | SFTP ] [⧉ 分屏开]
+--------------+--------------+
|  终端        |  SFTP        |
|  $ tar xzf  |  app/ logs/  |
|  app.tar.gz  |  app.tar.gz  |
+--------------+--------------+
```

命令和它要动的文件同时在屏幕上。这正是 MobaXterm、Xshell、WindTerm、Tabby 带火的那种布局——用过分屏的人，很少再愿意回去翻标签页。

## 开关在哪里

看**会话控制条**——终端窗格正上方那条细条，开头是 `SSH | SFTP` 类型标签的那条。类型标签后面就是那一排图标：

1. 回形针——SFTP 路径跟随终端
2. **分屏——就是这篇的主角**（两个并排的小矩形）
3. 心跳——服务器信息 / 监控
4. 广播——镜像输入到所有终端
5. ……右侧还有换行、全屏、搜索

点一下分屏图标，当前会话立刻在标签模式和分屏模式之间切换，**不用重连**。再点一下就回去。这个状态按会话标签页保存，所以 `web-01` 可以一直分屏，旁边的串口控制台照样全宽。

> 如果你没看到这个图标，说明这个会话没有 SFTP 窗格可分。打开一个同时勾选 `enableSsh` 和 `enableSftp` 的 SSH 书签——本地 shell、网页标签页、RDP/VNC、串口会话都没有第二格可显示。

## 30 秒第一次分屏

1. 打开任意开了 SFTP 的 SSH 书签。
2. 在会话控制条里找到分屏图标（回形针后面第二个）。
3. 点它。终端缩到左半边，SFTP 文件管理器从右边滑进来。
4. 再点一次。回到全宽标签页。

不用存设置，不用重连，不用开布局对话框。觉得分屏顺手就一直留着——标签页开着，分屏状态就一直在；想要整套布局下次一键恢复，用工作区存下来（见下文）。

## 什么时候分屏最爽

**解压即确认。** 左边 `tar xzf release.tar.gz`，右边立刻看到 `release/` 冒出来。不用翻标签页确认解压成功没有。

**改完即跑。** 在 SFTP 格里双击 `app.js` 本地编辑，保存即上传，`node app.js` 或 `systemctl restart app` 就在左边一眼的地方。

**追磁盘占用。** `du -sh *` 说 `logs/` 有 4 GB，文件夹本来就在右边摆着——右键下载或删除，收工。

**逛一台不熟的机器。** 左边 `cat docker-compose.yml`，右边项目树一直可见。不用再靠 `ls` 回忆结构，因为文件面板本身就是一个排好序、带大小、可点击的 `ls`。

**拖文件不用找地方。** 本地文件拖进 SFTP 格时终端一直可见，进度条一走完，安装命令立刻就能敲。

标签模式也有赢的时候：窄笔记本屏、想独占每一列的 `vim`、铺满屏的 `htop`。所以它是个开关而不是设置项——按任务翻，而不是按安装翻。

## 和路径跟随是绝配

分屏解决"两边一起看"，**SFTP 路径跟随终端**解决"两边看同一个目录"：shell 里 `cd`，文件面板跟过去；文件面板里点开文件夹，shell 跟过去。回形针图标就挨着分屏图标不是偶然——两个都打开，就是一个位置、两个视图。

完整故事：[SFTP 路径跟随终端](/blogs/sftp-path-follow-terminal/)。如果 `cd` 了面板不动，去那篇的排查清单里看（shell 得是 bash/zsh/sh/ash、得是同主机的窗格、跟随得真的开着）。

## 分屏 vs 会话布局 vs 工作区

三个名字像、活儿不一样：

|  | 分屏（这篇） | 会话布局 | 工作区 |
|---|---|---|---|
| **拆的是什么** | 一个会话标签页里的终端 + SFTP | 窗口里的多个会话标签页（2x2 网格、多列、多行） | 一切——标签页 + 布局，按名字存下来 |
| **入口** | 会话控制条里的分屏图标 | 布局控件 / 状态栏 | 工作区面板 |
| **保存吗** | 标签页开着就在 | 窗口开着就在 | 保存，一键恢复标签页 + 布局 |
| **配合** | 永远是起点 | 两台主机左右摆，每台再各自文件分屏 | "前端 + 后端 + 数据库，全部分屏"存成一个动作 |

典型终态：一个叫 `prod` 的工作区，一键打开 `web-01` 和 `db-01` 摆成两列，每个标签页都已经是终端 + SFTP 分屏且跟随打开。每天早上的 routine 变成一次点击。视频：[Electerm Session Layout](/videos/electerm-session-layout/)、[Electerm Workspace](/videos/electerm-workspace/)。

## 排查清单

1. **没有分屏图标？** 这个标签页不是 SSH+SFTP 会话。本地终端、网页、RDP/VNC、串口、纯 FTP 书签都没有第二格可显示。
2. **SFTP 格空白或报错？** SFTP 子系统没起来——权限、`Subsystem sftp` 服务端没开、连接断了。标签模式一样会失败，分屏只是让它看得见。
3. **觉得挤？** 这就是切回标签模式的信号。窄屏下切回去全宽，或者把窗口拉宽——分屏共用标签页的宽度。
4. **想默认分屏？** 目前没有"永远分屏"的全局开关。打开书签点一次，想下次自动恢复就把它存进工作区。

## 一句话备忘

- **开关** = 会话控制条里的分屏图标（两个小矩形），回形针后面那个。点一下 = 标签页 ↔ 左右分屏，不用重连。
- **标签模式** = 一次看一格（`SSH | SFTP` 切换），空间最大。**分屏模式** = 终端 + SFTP 同主机并排，不用来回翻。
- **前提** = SSH 书签同时打开 SSH 和 SFTP。其它会话类型没有东西可分。
- **好搭档** = 旁边的路径跟随开关。分屏管一起看，跟随管看同一个目录。
- **放大招** = 会话布局（多标签页同屏）+ 工作区（整套存下来）。
