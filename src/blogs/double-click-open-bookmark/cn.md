# 双击打开书签

在 electerm 里，点一下书签不是"选中"，而是"完成"：会话连上、标签页出现、侧边栏收起。这很快，如果你是从纯终端一路用过来的，这正是你要的。

但还有另一类人。文件管理器、IDE 的文件树、浏览器的书签管理器、Windows 资源管理器、访达的列表视图——点一下是**指向**，点两下才是**打开**。带着这个习惯的人，在 electerm 里绝不会只点一下书签。他们每次都点两下，而第二下落在了不该落的地方。

现在有了对应的开关：**双击打开书签**。

## 这个开关改了什么

位置在 **设置 → setting** 的通用开关列表里，默认**关闭**。你不打开它，什么都不会变。

| 操作 | 开关关闭（默认） | 开关打开 |
| --- | --- | --- |
| 单击书签 | **直接连接** | 只把该行标记为选中，不连接 |
| 双击书签 | 第一下已经连上了——第二下落在面板后面 | **连接** |
| 单击历史记录 | 用该记录打开一个会话 | 只标记该行 |
| 单击设置里的书签标签页 | 选中该书签以便编辑 | 不变 |
| 单击分组行 | 展开 / 折叠 | 不变 |
| 选中行上按回车 | 打开 | 不变 |
| 触屏点一下 | 打开 | 不变——该开关被忽略 |

只有前三行有区别，后面几行都是刻意的。

## 第二下为什么会出问题

electerm 不会把指向同一台主机的两个会话合并：每点一次书签就多一个标签页。所以"习惯性双击"的实际代价取决于一件事——你的侧边栏是不是钉住的。

**未钉住（默认）。** 第一下点下去，会话就开了，面板立刻收起，宽度上没有过渡动画可以点穿。于是你的第二下落在面板后面的东西上。多数时候是终端，只是把焦点给它，无所谓；有时候是一个标签页，或者 SFTP 文件列表，那就是一次真正落错的点击。

**已钉住。** 钉住的面板不会收起，两下都落在同一行上，结果是同一台主机开了两个标签页。

两种情况下的解法是同一个：让列表等一个明确的第二下再连。

## 历史记录列表其实最容易踩

历史记录面板比书签列表更像一个"浏览"界面。你打开它是为了找上周用过的那台主机，一边滚一边点着看——而开关关闭时，这些点按每一个都会真的开出一个会话。它也是每一行都带自己操作图标的那种列表，行尾正好是光标容易停的地方。

这个开关同时覆盖历史记录和书签，所以它是一个开关，而不是两个。

## 它刻意不动的地方

**设置里的书签标签页。** 设置 → 书签是一个编辑界面，不是启动器。在那里单击仍然是选中该行以便编辑，回车也仍然是选中而不是打开。这个开关管的是侧边栏。

**分组。** 分类行本来就是单击展开 / 折叠，双击等于连按两下、回到原地。所以 electerm 干脆忽略分组行上的双击——分类单击一下照样展开。

**回车。** 键盘激活本身就是明确意图，所以开关打开时，回车依然会打开选中的书签。纯键盘操作一点不损失。

**触屏。** 触屏没有双击，所以这个开关会被跳过，点一下照旧连接。

## 触屏的判断跟着指针走，不是跟着设备走

electerm 看的是你**当下真正在用的输入方式**，而不是硬件"能不能"触屏。一台带触摸屏的笔记本会被当作鼠标设备——开关生效——直到真的来了一次触摸或手写笔事件，这时才切换成"点按即连"。你再摸鼠标，它又切回来。二合一设备不会卡在错误的模式里，你也不用去猜它现在把自己当什么。

## 速查

- 在侧边栏里，一下点击就是完整动作。如果你的手习惯两下，打开 **双击打开书签**（设置 → setting，默认关闭）。
- 它作用于**侧边栏书签列表**和**历史记录列表**——这两个"点一下就启动"的地方。
- 它从不作用于**设置里的书签标签页**（那是编辑器）、**分组**（单击即切换）、**回车**，以及**触屏**。
- 面板**钉住**时，一次误双击会把同一台主机开两次；未钉住时，第二下落在面板后面的东西上。
- 触屏这个例外是实时跟随指针的，所以混合设备会表现得像你刚刚用过的那种输入方式。
